# Content formats

Read only relevant guidance. Its questions supplement the [brief](brief.md);
they are not mandatory forms.

| Intended use | Guide |
|---|---|
| Landing or product page | [Landing pages](content/landing-page.md) |
| Advertising, offers, or persuasion within another format | [Sales copy](content/sales-copy.md) |
| Article, blog, opinion, tutorial, or ebook | [Articles and ebooks](content/articles.md) |
| Caption, post, thread, or carousel | [Social media](content/social-media.md) |
| Personal, sales, newsletter, or transactional email | [Email](content/email.md) |
| Personal, group, service, or follow-up WhatsApp message | [WhatsApp](content/whatsapp.md) |
| Client presentation, slides, or pitch deck | [Presentations](content/presentations.md) |
| YouTube, Shorts, Reels, or another video script | [Video scripts](content/video-script.md) |
| Repository description, README, issue, PR, release notes, or GitHub Discussions | [GitHub](content/github.md) |
| Skill instructions and agent-facing references | [Skill instructions](content/skill-instructions.md) |

Purpose and format overlap. A sales email uses relevant parts of both guides
without duplicate questions. For unlisted types, use the closest guide and ask
only about differences that change the result. Platform alone does not set intimacy.
