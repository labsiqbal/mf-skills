# Skill instruction audit

Use for requested audits of the skill itself; assess writing with
[assessment](assessment.md). Clear instructions are not evidence of good outputs.
Read the entrypoint and references relevant to each claim. Behavioral evidence
requires actual prompts, sources, and outputs. Disclose authorship of the skill
or shared conversation context. Auditing does not authorize changing instructions.

| Aspect | Evidence sought |
|---|---|
| Triggers and scope | Relevant requests activate; discussion alone does not |
| Brief | Reuses context; waits for essential facts; no generation stereotypes |
| Reference routing | Reachable, conditional, consistent guidance |
| Language adaptation | Native conventions in both languages; preserved meaning |
| Audience readiness | No internal notes or unresolved placeholders in visible copy |
| Personal voice | Grounded attention and choices beyond pronouns or brevity |
| Meaning | Preserved actors, actions, causes, promises, and certainty |
| Format | Context-specific form rather than renamed headings |
| Test coverage | Diverse, sufficiently specified actual or simulated tasks |
| Assessment consistency | Quotes and reasons explain scores |
| Impact | Comparable with/without-skill evidence and specific user feedback |

Report locations, short quotes, impact, and proposed fixes using: adequate in
instructions; needs revision; not yet demonstrated. A claim can have adequate
instructions and unproven behavior. No aggregate score hiding those differences.
For requested tests use [tests](tests.md); prioritize meaning errors then voice
mismatches. Validator success and self-scoring alone do not prove improvement.
