# Jenis konten

Pilih berdasarkan pemakaian tulisan. Baca panduan yang relevan saja. Pertanyaan
di setiap panduan melengkapi [brief awal](brief.md), bukan formulir wajib.

| Pemakaian | Baca |
|---|---|
| Landing page atau halaman produk | [Landing page](konten/landing-page.md) |
| Iklan atau tulisan penawaran; kebutuhan persuasi dalam format lain | [Sales copy](konten/sales-copy.md) |
| Artikel, blog, opini, atau panduan | [Artikel](konten/artikel.md) |
| Caption, posting, utas, atau teks carousel | [Media sosial](konten/media-sosial.md) |
| Email pribadi, penawaran, newsletter, atau transaksi | [Email](konten/email.md) |
| Pesan WhatsApp pribadi, grup, layanan pelanggan, atau tindak lanjut | [WhatsApp](konten/whatsapp.md) |
| Slide presentasi, pitch deck, atau materi presentasi klien | [Presentasi](konten/presentasi.md) |
| Naskah YouTube, Shorts, Reels, atau video lain | [Naskah video](konten/naskah-video.md) |
| Deskripsi repo, README, issue, PR, release notes, atau GitHub Discussions | [GitHub](konten/github.md) |
| Instruksi skill dan referensi untuk agent | [Instruksi skill](konten/instruksi-skill.md) |

Bentuk dan tujuan bisa beririsan: email penawaran memakai panduan email serta
bagian sales copy yang relevan. Gabungkan kebutuhan tanpa mengulang pertanyaan.
Jika jenis belum tercantum, gunakan bentuk terdekat; tanyakan hanya perbedaan
yang mengubah hasil. Platform tidak otomatis menentukan tingkat keakraban.
