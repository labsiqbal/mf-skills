# Storylines

## a
Device: one agent run, followed from prompt to result inside the trace tree.
Form: a single continuous camera move down the timeline, no cuts until the end card.
Beats: prompt lands (bar 1), spans unfold (bars 2-3), a step fails red (bar 5), the fix turns it green (bar 7).
The logo locks up as the trace collapses into the mark (bars 9-10).

## b
Device: the eval scoreboard as a race between two prompt versions.
Form: bar cuts on every downbeat, ranked bars re-sort on each cut.
Beats: two prompts enter (bar 1), scores climb (bars 2-5), the new prompt overtakes (bar 6), cost per run stamps (bar 8).

## c
Device (the bold one): the whole film is typed into a terminal and the trace answers back.
Form: copy cuts, black ground, the trace tree draws itself as text art before resolving into the real UI.
Beats: a command types (bar 1), output streams (bars 2-4), the UI bursts out of the text (bar 5), real screens take over (bars 6-9).
End card on the typed tagline (bar 10).

Pick: a - one unbroken run shows the product doing its real job, which is the brief's signature moment.
